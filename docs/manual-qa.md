# 人工验收清单

> 在 Chrome 加载扩展后逐项执行。全部通过，才可把状态改为「P0 已实盘页面验收」。
> 页面：<https://www.jisilu.cn/web/data/cb/pre/>

## 0. 加载

1. Chrome 打开 `chrome://extensions`，开启「开发者模式」。
2. 「加载已解压的扩展程序」→ 选择 `jisilu-enhancer/` 目录。
3. 打开待发转债页，**确认页面原有的列、排序和链接都没被破坏**。

## 1. 注入列只出现一次

在「配售10张所需股数(股)」右侧应出现「配债所需资金」和「预估盈利·安全垫」两列。

- [ ] 两列各只出现一次
- [ ] 排序、筛选、翻页、刷新后不重复、不串列

## 2. 手算对账（最关键）

选 3 只**方案进展为「同意注册」、股权登记日为 `-`** 的标的（这些才是真正可潜伏的）。
用同一时点正股价手算 `整手股数 × 现价`，与插件逐项比对，**必须完全一致**。

| 项目 | 手工 | 插件 |
| --- | --- | --- |
| 理论股数（页面「配售10张所需股数」） | | |
| 实际买入股数（主板/创业板向上取整到 100） | | |
| 现价 | | |
| 配债所需资金 = 实际股数 × 现价 | | |
| 一手金额 | | |

参考样例（2026-09-06 抓取，价格会变，仅用于校验算法）：
华纬科技 `001380`，页面所需股数 471，现价 17.95 → 实际买入 500 股 → **¥8,975.00**。

## 3. 安全垫与配色

点击增强单元格，把「预估盈利（获配10张的总额）」调到恰好跨越 2% / 4% / 6% / 8% 的值。

- [ ] 满额安全垫、一手安全垫同步变化
- [ ] 颜色按 `<2% 红 / 2–4% 橙 / 4–6% 黄 / 6–8% 浅绿 / ≥8% 绿` 切换
- [ ] 留空时显示「待补」，**不显示 0%**

## 4. 持久化

- [ ] 设置一笔债的预估盈利、限售比例、备注 → 刷新页面仍在
- [ ] 重启 Chrome 后仍在，且不串到其它债
- [ ] 「恢复继承」能清掉该债的个性化值

## 5. 过期行不参与计算

对照下表，**这些行必须显示 `- / 待补` 而不是计算值**：

| 特征 | 期望提示 |
| --- | --- |
| 方案进展含「上市」 | 已上市，无需潜伏 |
| 股权登记日 ≤ 今天 | 股权登记日 XXXX-XX-XX 已到或已过 |
| 未识别正股代码 | 未识别正股代码 |

## 6. 行情与降级

- [ ] tooltip 显示行情来源与时间（腾讯财经 / 东方财富 / 集思录当前页面）
- [ ] 排序、翻页各 10 次，DevTools Network 中**同一正股不会短时间反复请求**
- [ ] 断网或拦截行情域名后，页面不报错、不卡死，显示缓存时间或「待补」

## 7. 记录

验收通过后，把日期和浏览器版本记到 `实施复盘与优化清单.md`。

> 任何价格、发行规模、配售资格和公告变动，一律以**当日公告**为准。本插件只是计算辅助，不构成投资建议。
