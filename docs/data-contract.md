# 数据合同：集思录待发转债页

> 抓取时间：2026-09-06 ｜ 页面：<https://www.jisilu.cn/web/data/cb/pre/> ｜ 插件版本：0.1.0
>
> 页面改版或数字对不上时，先回到这里核对字段，再去改代码。

## 1. 页面真实表头

页面是 Vue 单页应用，表格由 JS 渲染，**直接查看网页源码看不到任何表格**。以下是实际渲染后的 25 列：

| 索引 | 列名 | 插件是否使用 |
| --- | --- | --- |
| 0 | 代码 | ✅ 正股/转债代码 |
| 1 | 名称 | ✅ |
| 2 | 方案进展 | ✅ 识别「已上市」 |
| 3 | 进展公告日 | — |
| 4 | 发行规模(亿元) | ✅ 流通规模估算 |
| 5 | 类型 | — |
| 6 | 评级 | — |
| 7 | 股东配售率 | — |
| 8 | 转股价 | — |
| 9 | 正股价 | ✅ 行情源失效时的兜底价 |
| 10 | 正股涨幅 | — |
| 11 | 正股现价比转股价 | — |
| 12 | 正股PB | — |
| 13 | 百元股票含权(元) | — |
| 14 | 每股配售(元) | — |
| 15 | 配售10张所需股数(股) | ✅ 核心输入 |
| 16 | 股权登记日 | ✅ 潜伏截止日 |
| 17–24 | 网上规模、中签率、申购户数等 | — |

**关键事实：页面没有「正股代码」「正股名称」「申购日期」三列。**

- 正股代码只能从单元格里的链接 `/data/stock/301459` 或从「代码」列拆分得到。
- 「正股名称」不能放宽成「正股」去匹配，否则会命中「正股价」列。
- 潜伏截止日只能用**股权登记日**，不能用不存在的申购日期。

## 2. 代码列的两种形态

| 形态 | 示例 | 含义 | 解析 |
| --- | --- | --- | --- |
| 12 位 | `301459123283` | 已发/已上市：正股 301459 + 转债 123283 | 取链接 `/data/convert_bond_detail/123283` 得转债码作为设置主键 |
| 6 位 | `001380` | 待发（同意注册）：只有正股代码 | 正股代码兼作设置主键，注释已在代码中说明 |

设置主键必须稳定，否则每债的预估盈利会串到别的债上。

## 3. 行数据合同

每行标准化为：

```js
{
  bondCode, bondName, stockCode, stockName, market,
  requiredShares, issueSize, registrationDate, progress,
  pagePrice, price, priceTimestamp, priceSource, priceStale
}
```

缺关键字段就进入「不可计算」并显示原因，**绝不用 0 代替缺失值**。

## 4. 判定规则

| 场景 | 判定 | 界面 |
| --- | --- | --- |
| 方案进展含「上市」 | 不可潜伏 | `- / 待补`，提示「已上市，无需潜伏」 |
| 股权登记日 ≤ 今天（Asia/Shanghai） | 不可潜伏 | `- / 待补`，提示登记日已过 |
| 股权登记日为 `-` | 待定，**仍可计算** | 正常出数，tooltip 显示「待定」 |
| 未识别正股代码 | 不可计算 | `- / 待补` |

登记日当天按**保守口径**视为不可潜伏（与 P0 计划一致），避免诱导最后一刻操作。

## 5. 单位与口径

| 字段 | 单位 | 说明 |
| --- | --- | --- |
| 配售10张所需股数 | 股 | 页面权威输入，不自行换算 |
| 正股价 | 元 | 腾讯第 4 个字段；东财 `f43 / 100`（分转元） |
| 发行规模 | 亿元 | 锁定额与流通规模同单位，计算层禁止混用 |
| 限售/配售比例 | % | 输入 0–100，内部转小数 |

整手规则：主板/创业板 `ceil(股数/100)×100`；科创板 200 股起、超出按 1 股递增；北交所按 100 股。

## 6. 行情来源与降级

1. **腾讯财经** `qt.gtimg.cn`：批量请求，一次取全页；返回 **GBK**，必须 `TextDecoder('gbk')` 解码。
2. **东方财富** `push2.eastmoney.com`：逐个兜底。
3. **页面正股价**：两者都失败时的兜底。
4. 仍失败则显示最近一次有效缓存并标注「（缓存）」。

缓存 30 秒，同一批请求合并，避免翻页/排序造成请求风暴。

实测记录（2026-09-06）：东方财富在当前网络返回空响应，腾讯财经覆盖沪、深、创业板、科创板、北交所全部正常；腾讯取到的 17.95 元与页面正股价完全一致。
