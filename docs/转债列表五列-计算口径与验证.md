# 转债列表页估值五列 · 计算口径与数据链路

> jisilu-enhancer v0.5.0 新增：在集思录转债列表页 `/web/data/cb/list` 表格最右侧追加 5 列，把会员功能用**全公开免费数据**自己算出来。
> 本文是这五列的完整口径说明 + 数据源 + 验证记录。

## 一、五列定义与算法

| 列 | 算法 | 数据源 |
|---|---|---|
| **纯债价值** | 剩余票息 + 到期赎回价，按评级贴现率 XNPV 折现（Excel 式年复利） | 票息/赎回价：东财条款；贴现率：评级映射表（AAA 2.0%、AA+ 2.4%、AA 3.0%、AA- 3.8%、A+ 4.8%、A 5.8%…） |
| **期权价值** | B-S 欧式看涨（单股）× 转股比例（100/K） | S=正股价、K=转股价（DOM）、σ=正股波动率、T=剩余年限、r=1.7% |
| **理论价值** | 纯债价值 + 期权价值（分离定价，鹏元 2011 口径）；副值偏离度=(市价-理论)/理论 | 上两项之和 |
| **正股波动率** | 日收益率样本标准差 × √250（年化） | 腾讯日 K 前复权 320 条，缓存 24h |
| **回售收益** | 税前 YTM（复利，二分法解方程）：假设回售期首日触发，现金流=剩余票息+回售价（面值+当期利息或条款价） | 回售条款：东财 RESALE_CLAUSE 解析 |

## 二、回售收益四态（与集思录口径对齐）

| 状态 | 显示 | 含义 |
|---|---|---|
| 无回售条款 | `— 无回售条款` | 银行/券商债天生无回售条款（5 只） |
| 未到回售期 | `— 未到回售期` | 剩余年限 > 回售期年限+0.5（集思录此态显示 null） |
| 有解 | `-71.66% 税前YTM` | 在回售期内，复利 YTM 精确解 |
| 深亏无解 | `≪-95% 远低于回售价` | 价格远超回售价，收益率跌破二分法下限（集思录用简单年化会显示 -232% 之类，我们用复利口径更严谨） |

## 三、数据链路（全部免费、已实测）

```
DOM 行（30 列免费数据：价/K/评级/剩余年限/到期时间/回售触发价…）
  +
东财 RPT_BOND_CB_LIST（pageSize=500×3页，过滤退市后在市 318 只）
  → 票息 INTEREST_RATE_EXPLAIN（文字解析）
  → 到期赎回价 REDEEM_CLAUSE（文字解析，排除"有条件赎回"段 130%）
  → 回售条款 RESALE_CLAUSE（文字解析）
  → 缓存 chrome.storage 7 天（条款几乎不变）
  +
腾讯日 K（web.ifzq.gtimg.cn，每正股 320 条）
  → 年化波动率，并发 4 间隔 120ms，缓存 24h
```

**为什么不依赖集思录接口**：游客态 GET/POST 翻页参数均无效（只返回第一页 30 条），且会员字段用 `"buy"`/null 占位（接口真不给，必须自算）。DOM 提取为主最稳。

## 四、条款文字解析的三种格式变体（正则必须兼容）

1. **票息**：`第一年0.20%` 与 `第一年为0.2%`（"年为"变体）→ `年(?:为)?`
2. **赎回价**：`面值的110%` 与 `票面面值110.00%`（无"的"变体）→ `面值[的]?`；先按「有条件赎回」切段防误吃强赎 130%
3. **回售期**：`最后两个计息年度` 与 `最后一个计息年度`（润禾转02）→ 中文数字映射含「一」

实测覆盖率（318 只在市债）：票息 **100%**、赎回价 **98.4%**、回售条款 **98.4%**（其余显示「—」兜底）。

## 五、已知模型边界（诚实清单）

- **B-S 分离定价对深度实值债系统性偏高 4-11%**（忽略强赎条款压制，浙商《定价全景图》实测 BS 全样本误差 6.63% 同因）。理论价值列对平价 >130 的债会偏高估——这是模型特征，后续可升级 LSM 引擎修正。
- **贴现率是评级单一映射**，未按期限细分（集思录是「评级+期限 YTM」，同评级 1 年与 6 年差 0.3-0.8%）——纯债价值误差约 ±1 元内。
- **基金持仓做不了**（需基金季报，无免费实时源），按老板拍板跳过。
- 回售收益率为**税前**口径，税后 ×0.8。
