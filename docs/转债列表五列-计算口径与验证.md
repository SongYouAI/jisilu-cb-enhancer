## 0. 一句话概览

插件在集思录转债列表页 `/web/data/cb/list` 表格**最右侧**追加 5 列，把集思录的**会员功能**用**全公开免费数据自己算出来**：

| 列 | 一句话 | 数据来源 |
| --- | --- | --- |
| 纯债价值 | 把这张债当纯债值多少钱（债底） | 东财条款票息/赎回价 + 评级贴现率 |
| 期权价值 | 转股权的价值（B-S 欧式看涨×转股比） | 正股价/转股价/波动率/剩余年限 |
| 理论价值 | 纯债 + 期权（分离定价）；副值=偏离度 | 上两项之和 |
| 正股波动率 | 正股年化波动，衡量期权时间价值大小 | 腾讯日 K |
| 回售收益 | 假设回售期首日触发能拿到的年化收益（税前 YTM） | 东财回售条款 |

**为什么不直接用集思录会员列**：游客态接口会员字段用 `"buy"`/null 占位，**真不给数据**，必须自算。

## 1. 数据从哪来（输入逐项交代）

| # | 输入 | 来源 | 谁加工 | 可信度 |
| --- | --- | --- | --- | --- |
| ① | 现价、正股价、转股价、评级、剩余年限、到期时间、回售触发价 | 集思录列表页**原表格单元格** | 原样读取（转股价带「*下修1次」标注，取首个数字串） | 与页面一致 |
| ② | 票息结构、到期赎回价、回售条款 | 东财 `RPT_BOND_CB_LIST`（全市场 318 只在市债，缓存 7 天） | 插件正则解析**文字条款** | 文字解析覆盖 98%+ |
| ③ | 正股年化波动率 | 腾讯日 K（前复权 320 条，缓存 24h） | 插件算样本标准差×√250 | 实时行情 |
| ④ | 贴现率（纯债用） | 评级 → 企业债 YTM 映射表 `RATING_YTM` | 插件按评级查表 | 近似中债口径 |

### 1.1 为什么不依赖集思录接口

- 游客态 GET/POST **翻页参数均无效**（只返回第一页 30 条），全量数据拿不全。
- 会员字段（纯债/期权/波动率/回售）接口返回 `"buy"` 或 `null` 占位，**不是漏字段，是真不给**。
- 结论：**DOM 提取为主**（价格/转股价/评级/剩余年限这些免费可见列），东财补条款、腾讯补波动率、评级补贴现率。

### 1.2 列名 → 索引映射（`COLUMN_ALIASES`）

插件按表头文字定位原生列，兼容别名（`剩余规模(亿元)` / `剩余规模`）。主表判定：代码/现价/转股价/评级四列都能映射上才处理，**下修子表（无这些列）自动跳过**，避免误注入。

## 2. 第 1 列「纯债价值」——完整计算步骤

### 2.1 公式（XNPV，Excel 式年复利）

```
现金流 = 剩余各年中间票息 + 到期赎回价(含末息)
纯债价值 = Σ amount_i / (1 + ytm)^(days_i / 365)
```
- `ytm` = 评级对应的贴现率（小数），见下表。
- `days_i` = 第 i 笔现金流距今天的**自然日数**。
- 末息不再单列：到期赎回价已含最后一期利息，故到期日现金流 = `redeemPrice`（如 112 表示面值 100 + 末息 12）。

### 2.2 评级 → 贴现率表（`RATING_YTM`）

| 评级 | AAA | AA+ | AA | AA- | A+ | A | BBB+ | BBB | BBB- | BB | B | C |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 贴现率 | 2.0% | 2.4% | 3.0% | 3.8% | 4.8% | 5.8% | 7.0% | 7.5% | 9.0% | 12.0% | 15.0% | 20.0% |

> 未知评级按 `AA`(3.0%) 兜底。这是**单一评级映射**，未按期限细分（集思录是「评级+期限」两维 YTM），纯债价值误差约 ±1 元内——见 §9。

### 2.3 示意演算（AA，ytm=3.0%）

假设剩余 5 年，票息 `[0.3, 0.5, 1.0, 1.5, 2.0]`，赎回价 112：

```
第1年: 0.3 / 1.03^1 = 0.291
第2年: 0.5 / 1.03^2 = 0.471
第3年: 1.0 / 1.03^3 = 0.915
第4年: 1.5 / 1.03^4 = 1.333
第5年: (2.0+112) / 1.03^5 = 98.30
纯债价值 ≈ 101.23
```

### 2.4 实测值

- 润禾转02（A+）：纯债 **89.32**（债底合理，低评级高贴现）。
- 整体 318 只在市债纯债价值区间约 85～105，与主观预期一致。

## 3. 第 2 列「期权价值」——完整计算步骤

### 3.1 公式（Black-Scholes 欧式看涨，单股）

```
d1 = [ ln(S/K) + (r + σ²/2)·T ] / (σ·√T)
d2 = d1 − σ·√T
call(单股) = S·N(d1) − K·e^(−rT)·N(d2)
期权价值 = call(单股) × 转股比例，转股比例 = 100 / K
```
参数：
- `S` = 正股价；`K` = 转股价；`σ` = 正股年化波动率；`T` = 剩余年限（年）；`r` = **无风险利率 1.7%**。
- `N(x)` = 标准正态分布累计概率（Abramowitz & Stegun 26.2.17 近似，移植自 bond-valuator）。
- `σ` 未加载时用**默认 30%** 临时填充（首屏即出数，腾讯 K 线到位后替换为真实值）。

### 3.2 示意演算（平值附近）

S=10, K=10, σ=0.30, T=5, r=0.017：
```
d1 = [ln(1) + (0.017 + 0.09/2)×5] / (0.30×√5) = [0 + 0.31] / 0.671 = 0.462
d2 = 0.462 − 0.671 = −0.209
N(d1)=0.678, N(d2)=0.417
call = 10×0.678 − 10×e^(−0.085)×0.417 = 6.78 − 3.82 = 2.96
期权价值 = 2.96 × (100/10) = 29.6
```

### 3.3 实测值

- 严牌转债（深度实值）：期权 **125.88**（含显著时间价值，符合深度实值特征）。
- 平价附近的债期权价值通常 20～40，虚值债趋近 0。

## 4. 第 3 列「理论价值」+ 副值「偏离度」

### 4.1 公式

```
理论价值 = 纯债价值 + 期权价值        （分离定价，鹏元 2011 口径）
偏离度   = (市价 − 理论价值) / 理论价值
```
- 偏离度 **>0（红）**：市价高于理论，高估；**<0（绿）**：低估。
- 这是**理论中枢**，非买卖建议；深度实值债理论价系统偏高（见 §9），偏离度解读需结合 §9 边界。

### 4.2 恒等式自检

理论价值 ≡ 纯债 + 期权，**内部恒等式 29/29 精确成立，最大偏差 0**（双实现交叉校验，见 §10）。

## 5. 第 4 列「正股波动率」——完整计算步骤

### 5.1 公式

```
日收益率 r_t = close_t / close_{t-1} − 1
年化波动率 = std(r_t) × √250
```
- `close` = 腾讯日 K **前复权**收盘价，取最近约 **320 条**。
- `std` = 样本标准差（除以 n−1）。
- 可转债全年约 250 交易日，故乘 √250 年化。

### 5.2 实测值（量级合理）

| 正股 | 波动率 |
| --- | --- |
| 南京银行 | 21.3% |
| 牧原股份 | 32.0% |
| 润禾材料 | 55.8% |

> 银行股低波动、材料股高波动，符合常识。波动率未加载时该列暂用 30% 占位，腾讯 K 到位后刷新。

## 6. 第 5 列「回售收益」——完整计算步骤

### 6.1 公式（税前 YTM，二分法解方程）

假设**回售期首日即触发回售**：现金流 = 回售日前未付票息 + 回售价。

```
回售价 = 条款价（如 103） 或 面值+当期利息（100 + 当年票息）
解 r 使  Σ amount_i / (1+r)^t_i  =  现价
        r ∈ (−0.95, 10)，二分 100 次
```
- 已在回售期内 → 视为约 30 个自然日后触发（t 取小量）。
- `r < −0.95` 现值仍低于现价 → **无实数解**（深亏，见 §8）。

### 6.2 实测值

- 美锦转债（回售期内，有解）：**−71.66% 税前 YTM**。
- 洪城 / 万讯（价格远超回售价）：**≪−95%**（跌破二分下限，显示「远低于回售价」）。

## 7. 条款文字解析的三种格式变体（正则必须兼容）

东财返回的票息/赎回/回售是**自然语言条款**，必须正则解析。三种高频变体：

| 字段 | 变体 | 正则 |
| --- | --- | --- |
| 票息 | `第一年0.20%` vs `第一年为0.2%`（"年为"） | `第[一二三四五六七八九十\d]+年(?:为)?\s*(\d+(?:\.\d+)?)\s*%` |
| 赎回价 | `面值的110%` vs `票面面值110.00%`（无"的"） | `面值[的]?\s*(\d+(?:\.\d+)?)\s*%`，且**先按「有条件赎回」切段**防误吃强赎 130% |
| 回售期 | `最后两个计息年度` vs `最后一个计息年度`（润禾转02） | `最后([一两二三\d])\s*个?计息年度`，中文数字映射「一→1」 |

实测覆盖率（318 只在市债）：票息 **100%**、赎回价 **98.4%**、回售条款 **98.4%**（其余显示「—」兜底）。

## 8. 回售收益四态（与集思录口径对齐）

| 状态 | 显示 | 含义 |
| --- | --- | --- |
| 无回售条款 | `— 无回售条款` | 银行/券商债天生无回售条款（约 5 只） |
| 未到回售期 | `— 未到回售期` | 剩余年限 > 回售期年限 + 0.5（集思录此态显示 null） |
| 有解 | `−71.66% 税前YTM` | 在回售期内，复利 YTM 精确解 |
| 深亏无解 | `≪−95% 远低于回售价` | 价格远超回售价，收益率跌破二分法下限（非 NaN，避免误显「无回售条款」） |

> 关键纠偏：二分下限 −0.95 仍无实数解时**返回 NaN 并显「≪−95%」**，绝不能当成「无回售条款」（深亏债和真无条款债语义完全不同）。

## 9. 已知模型边界（诚实清单）

- **B-S 分离定价对深度实值债系统性偏高 4–11%**：忽略强赎条款对转股权价值的压制。浙商《可转债定价全景图》实测 BS 全样本误差 6.63% 同因——是**模型特征非 bug**，后续可升级 LSM 蒙特卡洛引擎修正。理论价值列对平价 >130 的债会偏高估，看偏离度时心里要有数。
- **贴现率按评级单一映射，未按期限细分**：集思录是「评级+期限」两维 YTM，同评级 1 年与 6 年差 0.3–0.8%，纯债价值误差约 ±1 元内。
- **基金持仓做不了**：需基金季报，无免费实时源，按老板拍板跳过该会员列。
- **回售收益率为税前口径**：税后约 ×0.8。
- **波动率首屏默认 30% 占位**：腾讯 K 线加载后刷新为真实值，期间理论价值/期权价值为临时值。
- **预估盈利（潜伏配债页）才是用户主观输入**；本页五列全部由公开数据客观计算，无主观预测。
